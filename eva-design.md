# Design Document for EVA - AI Chatbot Prototype

## 1. Introduction

### Purpose
This document outlines the design aspects of the EVA AI chatbot prototype, focusing on the user interface and experience of FPL customer service agents. The goal is to create a functional UI that simulates the intended interactions and features of the final product, emphasizing visual aids and session management.

### Scope
This design is centered on developing a standalone UI prototype with placeholder data, providing a framework for future integration with CRM and charger systems.

## 2. User Interface Design

### 2.1 User Interface Overview

#### Description
The UI will provide a clean, intuitive interface for customer service agents to interact with EVA, focusing on ease of use, efficient navigation, visual aids, and session management.

#### Key Elements

##### Chat Window
Central component where agents interact with EVA.

##### Indication of Active Agent ("Eva Mode")
Clearly display when an agent is interacting with EVA, including the name and identifier of the agent.

##### Start New Chat/Session
Provide a button or link to initiate a new session, allowing agents to reset interactions or handle multiple cases.

##### Common Question Prompts
Present a list of frequently asked questions or common issues, such as "Is the customer troubleshooting at home or in public?" to guide the conversation effectively while the agent is on the phone.

##### Information Panels
Sections for displaying customer information, charger status, error codes, and visual aids.

##### Initial Data Display
Immediately show crucial information such as the date last connected and any error messages currently displayed by the charger.

##### Visual Aids
Include images such as a breaker panel to check amperage, and the charger's LED halo in various colors (green, red, amber, blue) to diagnose errors.

##### Past Interactions
The AI chatbot should be able to pull context from previous customer service interactions. Agents should be able to easily access past conversation notes if needed.
